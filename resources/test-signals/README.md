# Test signals

The Multi-Mode Decoder's Test Signals menu plays these into the decoder. Each is a mono 16-bit WAV at 12000 Hz, listed in `index.json`.

## Generated

`tools/make_test_signals.js` makes every file except the two below, from the encoders in `tools/test_signals/`. Every callsign in them is made up: Q-prefixed calls such as Q1TST are never issued.

## Downloaded

Both are by Geryones (English Wikipedia), made with MixW, and released into the public domain by their author ("This applies worldwide"). Each was converted to 12000 Hz mono WAV.

- `olivia-16-500-wikimedia.wav`: Olivia 16/500 at 1500 Hz, from https://commons.wikimedia.org/wiki/File:OLIVIA_500_16_sample.ogg
- `olivia-32-1000-wikimedia.wav`: Olivia 32/1000 at about 1000 Hz, from https://commons.wikimedia.org/wiki/File:OLIVIA_1000_32_sample.ogg
