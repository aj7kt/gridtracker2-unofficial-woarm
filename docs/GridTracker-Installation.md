# Installing GridTracker2

Download the current version from [gridtracker.org/downloads](https://gridtracker.org/downloads/). Packages are available for Windows, macOS and Linux.

If you aren't familiar with downloading and installing software, see [Appendix A: Installing GridTracker2](Appendices/Appendix-A-Installing-GridTracker.md) for step-by-step instructions for each system.

Once it is installed, GridTracker2 keeps itself up to date: see [Updates](GridTracker-File-Storage.md#updates).
