# System Requirements

## Hardware

| | |
| --- | --- |
| Radio | An amateur radio transceiver, with a computer interface for digital modes |
| Computer | A PC with an Intel or AMD processor (64 or 32 bit), a Mac with an Intel or Apple Silicon processor, or an ARM computer running Linux, such as a Raspberry Pi |
| Monitor | 1024 × 768 or larger. A second or third monitor helps you watch WSJT-X, GridTracker2 and your SDR at once. |

## Operating Systems

| | |
| --- | --- |
| Windows | Windows 10 and 11. A separate build is available for Windows 7 and 8. |
| macOS | Recent versions of macOS, on Intel or Apple Silicon |
| Linux, Intel and AMD | Any recent 64-bit distribution with a graphical desktop |
| Linux, ARM | 32- and 64-bit ARM distributions, such as Raspberry Pi OS |

We only support operating systems that are still supported by their makers. If GridTracker2 runs on an older system you are welcome to use it, but we can't fix problems that only happen there.

## Other Software

GridTracker2 doesn't need any other program to run, but most of its live features come from a decoding program: [WSJT-X](https://wsjt.sourceforge.io/), [JTDX](https://jtdx.tech/), WS – Digital Mode Suite, MSHV or JS8Call-Improved. DX Feeds, POTA, SOTA and the online logbooks need an internet connection.
